Skeletons stand in for content while it loads. Compose several of them to mirror
the shape of the eventual layout. They are hidden from assistive technology.

<SkeletonExample client:load />

## Props

| Prop     | Type               | Default | Description          |
| -------- | ------------------ | ------- | -------------------- |
| `width`  | `string \| number` | —       | Explicit CSS width.  |
| `height` | `string \| number` | —       | Explicit CSS height. |

All native `<div>` attributes are also accepted.
